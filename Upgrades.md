# Upgrades to make to the app.

## plotter

### Zoom
- Allows to zoom on the plot by selecting an area or a section on the x or y axies

### Grid
- Shows gridlines based on how zoomed it is

### Variables
#### Variable names
- Allows to name the variables based on their order
#### Line thickness
- Allows to change the thickness of the lines
#### Offset
- Allows to offset each variable on the y axis
#### Gain
- Allows to multiply/divide the value of each variable

### Cursors
- Allows up to 4 cursors to be placed on the plot (2 vertical, 2 horizontal)

### Bar Plot
- Shows the values on the side of the plot as bars

### Multi plot support
- allows up to 4 different plots in which you can select which variables to show. All can be visible at once

### auto reconnect
- auto reconnects the com port

## Setting save
- saves the settings so that the next time the app is opened, the settings from the last sessions are still loaded
