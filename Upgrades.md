# Upgrades to make to the app.

All the upgrades below are implemented (checked 2026-11-13).

## plotter

- [x] Zoom: on an area of the plot, or a section of the X or Y axis
- [x] Grid: gridlines that follow the zoom
- [x] Variables: names, line thickness, offset, gain
- [x] Cursors: 2 vertical, 2 horizontal
- [x] Bar plot: the values as bars beside the plot
- [x] Multi plot support: several plots (now up to 8), each showing the variables chosen for it
- [x] Auto reconnect of the COM port

## Setting save
- [x] Settings saved, so the next session starts with the last one's settings
